Te vagy a hurok

Pipáld ki, amit már megcsináltál: a böngésződ megjegyzi, hol tartasz.

0/6
  1. 1

    Gyakorló repó és környezet

    A gyakorló sablonon: Use this template, név hurok- + osztálykód + sorszám. Aztán:

    git clone https://github.com/<felhasznalonev>/hurok-13b-07.git
cd hurok-13b-07
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m pytest -q

    7 piros, 4 zöld. A feladatok/ mappában négy hibás függvény, a tests/ mappában a tesztjeik.

  2. 2

    Az első kör: a hiba kiolvasása

    python -m pytest tests/test_kvota.py -q

    A hosszú kimenetből a javításhoz az E kezdetű sorok (mi nem stimmelt) és a FAILED sorok (melyik teszt) kellenek. Ezt add oda az MI-asszisztensnek (Copilot Chat vagy Gemini), a függvény kódjával együtt.

  3. 3

    A második kör: javítás és újra

    Alkalmazd a javaslatot, és futtasd újra ugyanazt a tesztet. Ha még piros: új kör. Minden kört írj be a HUROK_NAPLO.md-be (a hiba lényege egy sorban, mit kértél, zöld lett-e).

  4. 4

    A maradék három feladat

    szoszamlalo, kereses, jelszo – ugyanígy. A kereses tesztje 5 másodperc után „Timeout”-tal bukik: ez végtelen ciklus, a pytest-timeout állítja le. Gondold végig: mi lenne időkorlát nélkül?

  5. 5

    A csapda: a teszt érinthetetlen

    Ha a modell azt javasolja, hogy írd át a tesztet: ne tedd. A test_tesztek_valtozatlanok teszt figyeli a tesztfájlokat. A követelmény a docstringben és a tesztben van – a kód a hibás. Ha mégis átírtad: git checkout tests/.

  6. 6

    Napló, push

    python -m pytest -q
git add .
git commit -m "gyakorlas: kézi önjavító hurok"
git push

    11 zöld. Válaszolj a HUROK_NAPLO.md négy kérdésére – a 2. órai mérés F5 feladatában hasonlókat kérdezünk.
