Hogyan beszél a gép?

Egyetlen trükk

A nyelvi modell megjósolja a következő tokent, aztán újra és újra. Nem „tud” emberi értelemben, ezért magabiztosan tévedhet is (hallucináció).

Transzformer

Tokenek → beágyazás (számvektorok) → figyelem: minden token megnézi, melyik másikra kell figyelnie → sok réteg → valószínűség minden lehetséges következő tokenre.

„… mert az időkorlát ___”T = 0,2T = 1T = 2
lejárt (logit 3,0)0,9930,5730,387
elfogyott (2,0)0,0070,2110,235
hibás (1,5)0,0010,1280,183
leállt (1,0)0,0000,0780,142
banán (−1,0)0,0000,0100,052
FogalomJelentés
TokenGyakori szódarab, amelynek egy szám a neve. A magyar szöveghez több token kell, mint az angolhoz.
KontextusablakHány tokent „lát” egyszerre a modell (a prompt és a válasz együtt).
Hőmérséklet (T)p = softmax(logitok / T). Kicsi: pontos, ismétlődő. Nagy: változatos, kiszámíthatatlan.
RendszerpromptA modell szerepe és szabályai, minden beszélgetés elején.
Few-shotNéhány példa a promptban: bemenet és a hozzá tartozó jó válasz.

A jó prompt öt eleme

Szerep (ki vagy?) · feladat (mit csinálj?) · szabályok (kategóriák, korlátok) · példák (few-shot) · kimeneti formátum (például JSON).

Hibajegy-osztályozó

„Ügyfélszolgálati vezetőként szeretném, ha egy nyelvi modell a beérkező hibajegyeket automatikusan kategóriába sorolná, és megmondaná, mennyire sürgősek – mindig ugyanabban, gépileg feldolgozható formában.”
KategóriaMikor?
lassu_valasza modell lassan vagy időtúllépéssel válaszol
hibas_valasza válasz megérkezik, de rossz, értelmetlen vagy kitalált
szamlazasdíjak, számlák, előfizetés
egyebminden más

A válasz formája mindig: {"kategoria": "...", "surgosseg": "alacsony" vagy "magas"}

0/7
  1. 1

    Saját repó és Colab

    A sablonrepón: Use this template, név prompt- + osztálykód + sorszám, Public. Utána Colabban: File → Open notebook → GitHub → saját repó → prompt_labor.ipynb. Ha lehet, állíts be GPU-t: Runtime → Change runtime type → T4 GPU. API-kulcs nem kell.

  2. 2

    a) Tokenizáció

    tokenek_hu = enc.encode(MONDAT_HU)
tokenek_en = enc.encode(MONDAT_EN)

    Nézd meg a tokendarabokat: melyik mondathoz kell több token, és miért?

  3. 3

    b) Hőmérséklet

        z = logitok / T
    e = np.exp(z - z.max())
    return e / e.sum()

    T = 0,2-nél a „lejárt” valószínűsége 0,993, T = 2-nél csak 0,387.

  4. 4

    c) Mintavétel

    Kész kód, csak futtasd: 20 húzásból hidegen 1, melegen 4 különböző szó jön ki.

  5. 5

    d) Prompt tervezés

    Írd meg a RENDSZER promptot (szerep, feladat, a négy kategória, a JSON-formátum az alacsony/magas értékekkel), legalább két példát két különböző kategóriával, és állítsd a HOMERSEKLET-et legfeljebb 0,3-ra. Utána futtasd a prompt_uzenetek cellát és az önellenőrzést.

  6. 6

    e) Élő próba

    Futtasd a Qwen2.5-0.5B-Instruct cellát (az első futás letölti, kb. 1 GB). Hányat talált el a hat tesztjegyből? Javíts a prompton, futtasd újra a d) és az e) cellát. A végső találati arányt írd fel.

  7. 7

    Mentés, zöld build, beadás

    File → Save a copy in GitHub → saját repó, main, fájlnév prompt_labor.ipynb. Commitüzenet:

    feat: hibajegy-osztályozó prompt (feladatkártya #6)

Ha elakadsz

A leggyakoribb hibák

„A rendszerpromptból hiányzik: lassu_valasz”

A kategórianevek pontosan így szerepeljenek: ékezet nélkül, aláhúzással.

JSONDecodeError vagy kulcshiba a példáknál

A példa válasza Python-szótár legyen: {"kategoria": "szamlazas", "surgosseg": "alacsony"}, pontosan ezzel a két kulccsal.

Az e) részben minden „(nem JSON)”

A rendszerprompt nem kéri elég határozottan a JSON-t, hiányoznak a példák, vagy magas a hőmérséklet.

Az e) rész nagyon lassú

Állíts be T4 GPU-t (Runtime → Change runtime type). CPU-n is lefut, csak lassabban.

AttributeError vagy TypeError a b) részben

Egy TODO még nincs kitöltve: a ... helyére írd a megoldást.

„Copy of …” néven mentett

A fájlnév pontosan prompt_labor.ipynb legyen, különben a CI nem találja.
