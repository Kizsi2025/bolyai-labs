A gép mint párprogramozó

A prompt itt a kódod

Az IDE-asszisztens ugyanaz a nyelvi modell, mint a 6. blokkban. A promptja a nyitott fájlok, a kurzor körüli sorok, a nevek és a megjegyzések. Beszédes nevek és jó docstring mellett jobbak a javaslatai.

A kódért te felelsz

Az asszisztens magabiztosan javasol hibás vagy elavult kódot is. Titkos kulcs soha ne kerüljön a kódba vagy a chatbe. Amit nem értesz, azt ne fogadd el.

Hét lépés · VS Code-ban

Lépésről lépésre

Pipáld ki, amit már megcsináltál: a böngésződ megjegyzi, hol tartasz.

0/7
  1. 1

    Saját repó és klónozás

    A sablonrepón: Use this template, név refaktor- + osztálykód + sorszám, Public. Aztán klónozd és nyisd meg VS Code-ban:

    git clone https://github.com/<felhasznalonev>/refaktor-13b-07.git
cd refaktor-13b-07
code .
  2. 2

    Környezet és tesztek

    py -3 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m pytest -q

    Az eredmény: 9 piros, 10 zöld. A zöldek a viselkedési tesztek – ezeknek végig zöldnek kell maradniuk. VS Code-ban válaszd ki a .venv értelmezőt (Ctrl+Shift+P → Python: Select Interpreter).

  3. 3

    Copilot bekapcsolása

    Extensions (Ctrl+Shift+X) → GitHub Copilot és GitHub Copilot Chat (a repó ajánlja is őket) → bejelentkezés a saját GitHub-fiókoddal. A Copilot Free bármely fiókkal működik.

  4. 4

    a) Kódkiegészítés

    A segedek.py-ban töröld a raise NotImplementedError sorokat, és állj a docstring alá: a Copilot javasol (szürke szöveg). Tab: elfogad, Esc: elvet. Ellenőrizd:

    python -m pytest tests/test_segedek.py

    Zöld? Commit: git commit -am "feat: segédfüggvények"

  5. 5

    b) Refaktorálás kis lépésekben

    Jelöld ki a kódrészt a riport.py-ban, és kérj a Copilot Chattől egyszerre egy dolgot. Javasolt sorrend: global ki → konstansok a varázsszámok helyett → beolvasás csv.DictReader-rel → felbontás kis függvényekre → beszédes nevek. Minden lépés után:

    python -m pytest

    Ha a test_viselkedes piros lett: git restore riport.py, és kisebb lépésben újra. Ha zöld: commit.

  6. 6

    c) Dokumentáció és ruff

    Modul- és függvény-docstringek (Copilot Chat: /doc – de olvasd el, igaz-e!), típusjelölések minden paraméteren és visszatérési értéken. Ellenőrzés:

    ruff check .
python -m pytest

    Cél: 19 passed.

  7. 7

    d) AI-napló, push, beadás

    Töltsd ki az AI_NAPLO.md-t (minden TODO helyére 2–3 mondat). Utána:

    git add .
git commit -m "refactor: hívásriport rendbetétele (feladatkártya #7)"
git push

    Az Actions fülön a Feladatkártya 7 futás legyen zöld, aztán a repó linkje a Teams-feladatba.

Más lett a p90

A percentilis interpolál (statistics.quantiles, numpy). A docstring szerinti definíció kell: sorted(ertekek)[int(p / 100 * (n - 1))].

A teljes költség 0,01-gyel eltér

A régi kód a modellenként kerekített költségeket adja össze. A kerekítés sorrendje számít.

C901 … is too complex

A függvényben túl sok az elágazás vagy a ciklus: bontsd tovább.

PLR2004 Magic value used in comparison

A szám helyett nevezett konstans kell, például LASSU_HATAR_MS = 900.

A Copilot nem javasol semmit

Jelentkezz be a GitHub-fiókoddal (VS Code bal alsó sarka, fiók ikon), és nézd meg, nem fogyott-e el a havi keret. A feladat asszisztens nélkül is megoldható – ezt írd az AI-naplóba.
