A legfontosabb

Ami egyszer felkerült, az kiszivárgott

Ha egy kulcs a GitHubra került, nem elég törölni: a git-előzményben ott marad, a nyilvános repókat pedig robotok pásztázzák. A sorrend:

  1. Kulcscsere: az AI Studióban töröld a régi kulcsot, és az újat írd a .env-be. Ez az első lépés, mert a visszaélés percek alatt megtörténhet.
  2. git rm --cached .env, commit, push.
  3. Szólj a tanárnak: ha kell, közösen kitakarítjátok a git-előzményt.

A leggyakoribb hibák

„a gitben van, pedig nem lehetne: .env”

Először cseréld le a kulcsot az AI Studióban, aztán futtasd: git rm --cached .env, majd commit és push. Szólj a tanárnak is.

„nincs rögzítve”

Minden sor csomag==verzió alakú legyen. A pontos verziót a python -m pip freeze mutatja.

A CI-ben nem települ egy rögzített verzió

Az a verzió nem fut Python 3.12-n. Nézd meg a hibaüzenetet, és válassz olyan verziót, amelyik települ.

S608 (SQL-összefűzés)

A SQL-be ne f-stringgel tedd az értéket, hanem ? paraméterrel: execute("… WHERE id = ?", (azon,)).

A BETA.md-ben piros sor van

A sor megmondja, melyik ellenőrzés bukott el. Futtasd azt külön (pl. python doksi_futtat.py), javítsd, és utána a python kiadas_futtat.py-t újra.

„a címke már létezik”

A kiadott címkét nem mozgatjuk. Javítsd a hibát, és adj ki új verziót: 0.8.1-beta.
