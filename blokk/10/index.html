A program beszélget a modellel

Egy HTTP-kérés

POST a …/chat/completions címre, fejlécben Authorization: Bearer <kulcs>, törzsben JSON: model, messages, temperature, JSON módban response_format. A válasz: státuszkód és choices[0].message.content.

A titkok szabálya

Az API-kulcs pénz. A .env fájlban van, amelyet a .gitignore kizár. Soha nem kerül a kódba, a GitHubra vagy chatbe. Ha kiszivárgott: azonnal szólj, a kulcsot le kell tiltani.

VálaszJelentésTeendő

JSON mód és javító kör

JSON módban a modell JSON-objektumot ad – de így is tévedhet: hiányzó kulcs, kitalált kategória, ```json keret. Ezért a kód ellenőrzi, és ha rossz, visszaküldi a hibát a modellnek egy javító kéréssel, legfeljebb háromszor.

Hogyan tesztel a CI kulcs nélkül?

A tests/conftest.py egy ál-LLM-szervert indít, amely úgy válaszol, mint egy igazi OpenAI-kompatibilis API – csak előre megírt sorrendben, hibákkal (429, 503, 401) és rossz JSON-nal együtt. Így az is tesztelhető, amit élőben ritkán látsz.

Ha elakadsz

A leggyakoribb hibák

RuntimeError: Állítsd be az LLM_BASE_URL …

Nincs .env, vagy nem a repó gyökerében van. Másold le a .env.pelda-t.

404 a /chat/completions címre

A cím végéről hiányzik a /v1 (Ollama) vagy az /openai (Gemini), vagy dupla / került bele.

401

Rossz vagy hiányzó kulcs; szóköz vagy idézőjel került a .env-be.

400 „model not found”

A modellnév elírás vagy elavult. Ollamánál: ollama pull <modell>.

A tesztek nagyon lassan futnak

Az újrapróbálás várakozását import time és time.sleep(…) formában írd, így a teszt ki tudja kapcsolni.

A .env megjelent a git status listájában

Hiányzik a .gitignore-ból. Ha már commitoltad: git rm --cached .env, és szólj a tanárnak, mert a kulcsot cserélni kell.
