1. óra

Forrásanyagot adsz, a kitalálást kizárod

Írj termék-README-t ezekkel a fejezetekkel:
Mi ez? · Telepítés · Futtatás · Használat · Tesztek · Csapat
Anyag: a régi README, requirements.txt, .env.pelda, projekt.yaml, HALADAS.md (bemásolva).
Csak olyan parancsot és fájlt írj, ami a megadott anyagban szerepel.
Ha valamit nem tudsz, írj [KÉRDÉS] jelölést – ne találd ki.
Windows, PowerShell. Magyarul, diákoknak és fejlesztőknek.
Aztán soronként ellenőrzöl

Minden parancsot lefuttatsz, minden fájlnevet megnézel. A leggyakoribb MI-hibák: source .venv/bin/activate (ez Linuxra való, nem Windowsra), egy kitalált python main.py, egy kimaradt .env-beállítás. Amit javítottál, beírod a docs/MI_NAPLO.md-be.

Docs as code

Amit a gép meg tud nézni, azt nézze meg

python doksi_futtat.py ellenoriz   # hivatkozások, parancsok, .env-beállítások, kitöltetlen részek, kulcsok
python doksi_futtat.py api         # a docs/API_REFERENCIA.md újragenerálása a kódból

Mit lát az ellenőrző?

Hogy élnek-e a relatív linkek és képek, léteznek-e a parancsokban szereplő fájlok, leírja-e a README a .env.pelda minden sorát, és maradt-e benne TODO, PÉLDA, ___ vagy kulcs.

Mit nem lát?

Hogy igaz-e, amit a rendszer viselkedéséről írtál. Azt neked kell a kóddal összevetned, és ezért kell a doksiteszt.

A leggyakoribb hibák

„nem létező hivatkozás”

A link a fájlhoz képest relatív: a docs/ARCHITEKTURA.md-ből adr/0001-….md, a README-ből docs/adr/0001-….md. A kis- és nagybetű is számít.

„a parancsban szereplő fájl nem létezik”

Az MI kitalált egy fájlt (gyakran main.py vagy app.py). Javítsd a valódira, és írd be az MI-naplóba.

„a README nem írja le a .env-mintafájl beállítását”

A .env.pelda minden KULCS= sorát meg kell nevezni a README-ben, mindegyiket egy mondattal.

„kitöltetlen rész”

TODO, PÉLDA vagy ___ maradt a szövegben. Kódblokkban és `…` között nem számít hibának.

Az API-referencia „nem egyezik a kóddal”

Futtasd: python doksi_futtat.py api, és a fájlt is commitold. Ha rossz benne valami, a kódban javítsd, ne a fájlban.

Az első sor legyen flowchart LR (vagy TB, sequenceDiagram, erDiagram), és a blokk ```mermaid sorral kezdődjön.
