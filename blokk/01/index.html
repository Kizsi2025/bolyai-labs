Feladatkártya #1

Működő fejlesztői környezet

„Fejlesztőként szeretnék egy izolált Python-környezetet a szükséges könyvtárakkal, hogy a projekt függőségei ne ütközzenek más projektekkel, és a csapat bármelyik gépén ugyanígy fusson.”

Elfogadási feltételek

  • saját repó a sablonból, klónozva; a .venv létrehozva és aktiválva
  • a numpy és a pandas telepítve, a check_env.py hiba nélkül lefut
  • a requirements.txt feltöltve, mindkét csomaggal
  • a CI-futás zöld az Actions fülön
  • a repó linkje beadva a Teams-feladatba
Hét lépés · Windows, PowerShell

Lépésről lépésre

Pipáld ki, amit már megcsináltál: a böngésződ megjegyzi, hol tartasz.

0/7
  1. 1

    Saját repó a sablonból

    Nyisd meg a sablonrepót, és kattints a Use this template → Create a new repository gombra. Név: osztálykód és sorszám, teljes név nélkül (például onboarding-13b-07). Láthatóság: Public.

  2. 2

    Klónozás

    A saját repód címét a zöld Code gombnál találod.

    git clone https://github.com/<felhasználóneved>/onboarding-13b-07.git
cd onboarding-13b-07
  3. 3

    Virtuális környezet

    Aktiválás után a sor elején megjelenik a (.venv) jelzés.

    py -3 -m venv .venv
.venv\Scripts\Activate.ps1
  4. 4

    Csomagok és értelmező

    python -m pip install numpy pandas

    VS Code-ban: Ctrl+Shift+P → Python: Select Interpreter, és válaszd a .venv-beli Pythont.

  5. 5

    Ellenőrző szkript

    python check_env.py

    Ha ezt látod, kész a környezet (a verziószámok nálad eltérhetnek, az átlag nem):

    Python: 3.12.x
NumPy: 2.x.x
Pandas: 2.x.x
Sorok száma: 6
Átlagos válaszidő: 663.3 ms
A környezet rendben van.
  6. 6

    Commit és push

    Az Out-File miatt lesz a fájl UTF-8 kódolású.

    python -m pip freeze | Out-File -Encoding utf8 requirements.txt
git add requirements.txt
git commit -m "feat: fejlesztői környezet beállítása (feladatkártya #1)"
git push
  7. 7

    Zöld build és beadás

    Nyisd meg a repód Actions fülét, és várd meg a futást. Zöld pipa: kész. Piros X: kattints rá, nézd meg, melyik teszt bukott el, javítsd, és töltsd fel újra. Zöld build után a repód linkjét add be a Teams-feladatba.

Ha elakadsz

A leggyakoribb hibák

Az Activate.ps1 nem fut („running scripts is disabled”) 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Vagy cmd-ben: .venv\Scripts\activate.bat

A python parancs a Microsoft Store-t nyitja meg

Használd a py -3 indítót a python helyett.

A pip nem éri el az internetet 
python -m pip install --no-index --find-links <wheels mappa> numpy pandas

A wheels mappa helyét a tanár felírja a táblára.

A VS Code nem találja a pandast

Rossz értelmező van kiválasztva: Ctrl+Shift+P → Python: Select Interpreter, majd a .venv-beli Python.

Piros build: „Hiányzik a requirements.txt”

A fájl nem került be a commitba. Futtasd: git status, majd git add requirements.txt, commit, push.

A .venv mappa felkerült a repóba 
git rm -r --cached .venv
git commit -m "fix: .venv eltávolítása a repóból"
git push
B-terv · csak ha a 25. percre sem áll fel

Ma Colabban is teljesítheted

  1. Colabban: File → Open notebook → GitHub fül.
  2. Keress rá a GitHub-felhasználónevedre, és válaszd a saját repódat.
  3. Nyisd meg az onboarding_colab.ipynb-t, és futtasd a cellát.
  4. File → Save a copy in GitHub, majd add be a repó linkjét Teamsben.

Ma ez egyenértékű a zöld builddel. A helyi környezetet a 2. blokk első 10 percében pótolod.

Az 1. óra anyaga

Négy kör egymásban

Minden generatív MI mélytanulás, minden mélytanulás gépi tanulás, minden gépi tanulás MI. Fordítva nem.

MI

Intelligensnek tűnő viselkedés, akár kézzel írt szabályokkal. Példa: sakkmotor.

ML

A szabályokat adatból tanulja. Példa: spamszűrő.

DL

Sokrétegű neurális hálók. Példa: arcfelismerés.

GenAI

Új tartalmat hoz létre. Példa: kódkiegészítő.

Felügyelt tanulás

Címkézett példákból tanul. Osztályozás: spam vagy nem? Regresszió: mennyi lesz a lakás ára?

Felügyelet nélküli tanulás

Címke nélkül keres mintázatot. Klaszterezés: milyen vásárlócsoportok vannak? Anomália: mi szokatlan?

Egész évre
